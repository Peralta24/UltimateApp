## Arquitectura inicial

La app usará una arquitectura basada en MVVM.

## Capas

### Views

Pantallas creadas con SwiftUI.

### ViewModels

Manejan el estado y la lógica de presentación.

### Models

Representan los datos de la aplicación.

### Services

Se encargan de comunicación con APIs, almacenamiento y lógica externa.

## Herramientas relacionadas

- SwiftUI para UI
- SwiftLint para calidad de código
- Postman para probar APIs
- Obsidian para documentación
- GitHub para control de versiones
