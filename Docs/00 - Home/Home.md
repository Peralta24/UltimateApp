# UltimateApp Documentation

## Descripción

UltimateApp es una aplicación iOS desarrollada con SwiftUI. El objetivo del proyecto es practicar un flujo profesional de desarrollo móvil usando Xcode, GitHub, documentación técnica, control de versiones y buenas prácticas de arquitectura.

## Stack principal

- Swift
- SwiftUI
- Xcode
- Core Data
- Git & GitHub
- GitHub Desktop
- SwiftLint
- Obsidian para documentación
- Postman para pruebas de API
- Figma para diseño UI/UX

## Flujo de trabajo

1. Diseñar pantallas base en Figma.
2. Documentar la idea o feature en Obsidian.
3. Crear la estructura en Xcode.
4. Programar la funcionalidad.
5. Probar APIs en Postman.
6. Revisar código con SwiftLint.
7. Hacer commit y push en GitHub.
